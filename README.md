Lantern Row — a spot-the-difference game. Two near-identical night-market
alleys side by side; find 7 differences in Dusk Market, 8 in Rainy Alley,
9 in Festival Night, against the clock. Click (or arrow-key + Enter) to mark,
H for a hint, P to pause.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
